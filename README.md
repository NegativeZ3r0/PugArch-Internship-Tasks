### Running setup for development
1. git clone the repository and move into project directory
```bash
$ git clone <repo-link>
$ cd internship-tasks
```

2. install project dependecies
```bash
$ npm ci && cd myApp && npm ci
```

3. start development server
```bash
$ npx ionic serve
```
